# Руководство по HTTPS/WSS для ESP32 Air Quality Monitor

## 🔐 Обзор

Проект поддерживает защищённые соединения HTTPS и WSS (WebSocket Secure) напрямую на ESP32 без обратного прокси.

### Что поддерживается:
- ✅ **HTTPS** (порт 443 по умолчанию)
- ✅ **WSS** (WebSocket Secure, порт 8443 по умолчанию)
- ✅ **Самоподписанные сертификаты**
- ✅ **Загрузка сертификатов с SD карты**
- ✅ **Одновременная работа HTTP + HTTPS**

---

## 🚀 Быстрый старт

### 1. Генерация SSL сертификатов

```powershell
# Из корня проекта
.\generate_ssl.ps1 -CommonName "esp32.local"
```

**Результат:**
```
data/ssl/server.crt  - SSL сертификат
data/ssl/server.key  - Приватный ключ
```

### 2. Копирование на SD карту

```powershell
.\prepare_sd.ps1 -SdLetter L
```

Скрипт автоматически скопирует SSL сертификаты в `/ssl/` на SD карте.

### 3. Включение HTTPS в config.json

На SD карте отредактируйте `/config/config.json`:

```json
{
  "ssl": {
    "https_enabled": true,
    "wss_enabled": true,
    "https_port": 443,
    "wss_port": 8443,
    "cert_path": "/ssl/server.crt",
    "key_path": "/ssl/server.key"
  }
}
```

### 4. Загрузка прошивки

```bash
pio run -t upload
```

### 5. Проверка работы

Откройте в браузере:
```
https://<ip-esp32>/
```

> ⚠️ Браузер покажет предупреждение о самоподписанном сертификате - это нормально!

## ⚙️ Параметры конфигурации SSL

```json
{
  "ssl": {
    "https_enabled": true,        // Включить HTTPS сервер
    "wss_enabled": true,          // Включить WSS сервер
    "https_port": 443,            // Порт HTTPS
    "wss_port": 8443,             // Порт WSS
    "cert_path": "/ssl/server.crt",  // Путь к сертификату на SD
    "key_path": "/ssl/server.key",   // Путь к ключу на SD
    "use_self_signed": true,      // Использовать самоподписанный сертификат
    "common_name": "esp32.local", // Имя хоста в сертификате
    "cert_validity_days": 3650    // Срок действия (дни)
  }
}
```

## 🔧 Генерация сертификатов

### Простая команда:
```powershell
.\generate_ssl.ps1
```

### С параметрами:
```powershell
.\generate_ssl.ps1 -CommonName "my-esp32.local"
```

### Вручную через OpenSSL:
```bash
openssl req -x509 -newkey rsa:2048 \
  -keyout server.key -out server.crt \
  -days 3650 -nodes \
  -subj "/CN=esp32.local"
```

## ⚠️ Важные ограничения

### RAM использование
| Режим | RAM |
|-------|-----|
| **HTTP только** | ~0 KB дополнительно |
| **HTTPS активен** | ~48 KB |
| **Макс. клиентов** | 3 одновременных |

### Производительность
- **TLS handshake:** 2-5 секунд
- **Макс. запросов/сек:** ~10
- **Рекомендуется:** Локальная сеть

### Браузерные предупреждения
Самоподписанные сертификаты вызывают предупреждение в браузере. Это нормально для локального использования.

## 🔍 Устранение проблем

### HTTPS не запускается

**Симптомы:**
```
[ERROR] Failed to load SSL certificates
```

**Решения:**
1. Проверьте наличие файлов на SD:
   ```
   /ssl/server.crt
   /ssl/server.key
   ```

2. Перегенерируйте сертификаты:
   ```powershell
   .\generate_ssl.ps1
   .\prepare_sd.ps1 -SdLetter L
   ```

3. Проверьте config.json:
   ```json
   {"ssl": {"https_enabled": true}}
   ```

### Браузер блокирует соединение

**Chrome/Edge:**
1. Кликните "Дополнительные"
2. "Перейти на сайт (небезопасно)"

**Firefox:**
1. "Дополнительно"
2. "Принять риск и продолжить"

### WSS не подключается

**Проверьте:**
1. Порт 8443 открыт
2. Используется `wss://` вместо `ws://`
3. Сертификат загружен

## 📊 Сравнение HTTP vs HTTPS

| Параметр | HTTP | HTTPS |
|----------|------|-------|
| **Порт** | 80 | 443 |
| **Шифрование** | ❌ Нет | ✅ Да |
| **RAM** | 0 KB | 48 KB |
| **Скорость** | Быстро | Медленнее (handshake) |
| **Безопасность** | Низкая | Высокая |
| **Рекомендуется** | Локальная сеть | Интернет/важные данные |

## 🎯 Рекомендации по использованию

### ✅ Когда использовать HTTPS:
- Доступ из интернета
- Передача конфиденциальных данных
- Требования безопасности
- Интеграция с внешними сервисами

### ❌ Когда HTTP достаточно:
- Только локальная сеть
- Быстрые обновления данных
- Ограниченная RAM
- Тестирование

## 🔐 Безопасность

### Важно знать:
1. **Самоподписанные сертификаты** не обеспечивают аутентификацию
2. **Приватный ключ** хранится на SD карте в открытом виде
3. **HTTPS** защищает только транспорт, не данные на SD карте

### Рекомендации:
- Используйте VPN вместо HTTPS для локальной сети
- Ограничьте доступ к SD карте
- Регулярно меняйте сертификаты
- Не храните пароли в открытом виде
